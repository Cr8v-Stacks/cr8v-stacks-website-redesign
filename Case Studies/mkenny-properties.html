Mkenny Properties: Property Archive & Widget Engine

Overview

The Strategic Challenge
& Engineered Solution

Mkenny Properties' legacy site was a static brochure with no dynamic catalog or lead qualification mechanisms. High-intent property investors were unable to filter developments by location, price, or development status online.

We engineered a bespoke WordPress development catalog: modular Elementor listing widgets, sub-second AJAX taxonomy facet filtering, and automated broker routing that converts visitors directly into sales inquiries.

01 / Custom Elementor Widget System

Engineered modular drag-and-drop property cards and dynamic query loop builders tailored for the client editorial team.

02 / High-Velocity AJAX Query Engine

Constructed lightweight custom SQL query routines delivering instantaneous multi-facet filtering across price, status, and location.

03 / Dynamic Neighborhood & Map Schema

Integrated interactive location maps and structured RealEstateListing JSON-LD schema for dominant local search visibility.

04 / Direct WhatsApp Broker Routing

Engineered instant property metadata passing into direct broker WhatsApp inquiries, accelerating deal conversion rates.

Design & Engineering

Core Technical Deliverables

Design System // Asset 01

Custom Elementor Widget Suite

Constructed reusable UI components, property badge states (Featured, Sold Out, Under Offer), and typography tokens mapped directly into Elementor theme templates.

Query Engine // Asset 02

AJAX Property Filter Matrix

Engineered sub-second facet filtering for location zones, property types (Duplex, Terrace, Land), and budget sliders with zero page reloads.

Ecosystem Velocity // Asset 03

Custom Post Architecture & Direct Lead Sovereignty

Rather than relying on third-party property portal aggregators that divert inquiries to competing agencies, we architected an independent WordPress property catalog pipeline that keeps all buyer data and direct inquiries proprietary to Mkenny.

01 Custom Post Type & ACF Schema: Clean property data architecture supporting bedrooms, document title types, and floor plans.
02 Cached WP_Query Optimization: Sub-120ms database response times across high-density image catalogs.
03 Automated Broker Routing: Dynamic pre-filled WhatsApp lead dispatch connecting prospective buyers to the assigned agent.
