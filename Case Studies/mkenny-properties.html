Case Study

Mkenny Properties
From Landing Page to Platform

Rebuilding a basic static landing page into a fully functional property-listing and lead-acquisition platform with custom Elementor widgets.

Client Mkenny Properties
Starting State Basic 2-Page Static Site
Agency Scope FSE WordPress Dev & Custom widgets
Integrations Dynamic Listing Query Engine

The Challenge

Mkenny Properties came to us running a very basic, static landing page with only "Contact" and "About" sections. While their portfolio of premium real-estate listings was expanding rapidly, they had no way to showcase listings dynamically, process property-specific inquiries, or host an active search archive.

They needed to rebuild the site into a comprehensive, multi-page property platform. However, the site administration had to remain simple. Their internal non-technical staff needed to be able to add, modify, or archive listings easily without breaking the front-end layout or editing complex database tables.

The Solution

We designed and engineered a full-scale WordPress platform, custom-coding a bespoke Elementor widget system to handle dynamic database query listing results cleanly on the front end.

1. 4 New Dynamic Page Architecture templates

We expanded the platform from a simple landing page into a multi-tiered hierarchy. We coded four unique page templates: a main listings index grid, a single property detailed page with inline contact forms, an active blog for market insights, and structured archive search pages.

2. Custom Elementor Extension System

To let their team manage content easily, we built a custom Elementor extension widget pack specifically for this project. Instead of managing complex code, their team simply selects the "Mkenny Properties Grid" widget in their editor to automatically pull, filter, and render active listings by area, price, or property type.

Our Approach

We executed the overhaul through a four-phase development roadmap, balancing architectural scaling with simple publishing workflows.

01
Research & Listing Auditing

We researched how property hunters search for real-estate locally, auditing user behaviors and competitors' filtering systems. This informed how we structured Mkenny's listing database schemas.

02
Custom Widget Development

We coded a secure WordPress/Elementor addon widget pack, compiling PHP queries to query custom post types (CPTs) dynamically on the server without slowing down load speeds.

03
UX Design & Layout Iterations

We modeled and refined the design directly with the client. We focused on clear visual properties, high-contrast listing images, and simple call-to-actions placed next to agent profiles.

04
Integration & Technical SEO

We mapped the four new page types and indexed them natively on search engines, applying property schema tags, speed tuning, and training their staff to upload new properties in minutes.
