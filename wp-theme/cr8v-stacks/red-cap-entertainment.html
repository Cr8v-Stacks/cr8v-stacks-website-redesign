SYSTEM 02 // TIMESTAMP CALCULUS

Automated Event Lifecycle Calculus

Built into cpt-events.php. Evaluates event timestamps against current server epoch time via cr8v_is_event_past(). Concluded events automatically disable calendar download actions and transition into historical curatorial archives.

function cr8v_is_event_past($post_id) {
  $event_time = get_post_meta($post_id, '_cr8v_event_timestamp', true);
  return ($event_time < current_time('timestamp'));
}
